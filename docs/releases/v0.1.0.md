# Cairn v0.1.0 — Windows 预发布版

> 状态：本 Release 已于 2026-10-30 撤回并转为草稿，公开下载暂停；原附件保留。以下为旧版的历史发布记录，不代表最新源码或新安装包已发布。

这是 Cairn 的首个 Windows 试用版本，面向个人项目知识与任务协作。当前标记为预发布版；macOS 和 Linux 后续推进。

## 本版内容

- 当前用户安装、手动同目录更新和保留数据的卸载；应用管理本机数据库、API 与后台任务。
- Cairn 图标、明暗主题和与页面同步的窗口标题栏；设置在登录后的账户菜单中。
- 项目、任务、阶段、里程碑、依赖节点图、工时与项目产能情景。
- 项目知识工作台、资料上传与读取、引用定位、私有多轮对话和助手配置。
- 项目分析、可审阅规划、确认后执行的项目操作及执行记录。
- 回答模型和 1024 维知识索引服务分别配置，凭据由当前 Windows 用户的 DPAPI 加密保存；备份不包含模型凭据。

## 安装与更新

本次实机验证平台为 Windows 11 x64。安装前需具备 .NET Framework 4.8 与 Microsoft Edge WebView2 Runtime；缺少组件时安装器会提示官方下载地址。

下载 `Cairn-0.1.0-Windows-x64.exe`，并对照 `SHA256SUMS.txt` 检查文件。安装只作用于当前用户。完整程序路径须使用 ASCII 字符，可以包含空格；数据目录可以使用中文。

更新前正常关闭应用，并从「账户 → 设置 → 数据管理」保存备份，再运行新安装器并选择原程序目录。卸载保留用户数据与未知文件。详见[桌面说明](../../apps/desktop/README.md)。

## 已验证范围

- Windows 安装、同目录更新、卸载及数据保留；最终安装包文件清单与实际安装内容一致。
- 本地服务启动与关闭、加密模型配置、设置对话框、页面失败重试、明暗窗口外观。
- DeepSeek `deepseek-flash` 经 `openai-responses` 接口完成合成资料的带引用回答、流式返回和软件内项目分析。此结果不代表所有模型或任意资料集均已验收。
- 完整仓库门禁与受影响的前端、原生窗口检查；发布 PR 的 CI 状态可在仓库中查看。

## 已知限制

- 安装包尚未签名；当前更新方式为手动安装，没有自动更新。
- 真实知识索引仍需单独配置并验收 1024 维 Embedding 服务；配置回答模型不等于已具备索引服务。
- 公开 GitHub Skills 导入、飞书上游撤权与删除仍有外部验收待完成；桌面版尚无飞书服务凭据配置入口。
- 密码找回、团队邀请、多组织切换及更广泛的自主 Agent 能力尚未交付。
- 不支持跨平台数据库恢复或数据库大版本自动升级。

源代码采用 ISC 许可证。安装包内保留 Cairn 及随包组件的许可证文件。
