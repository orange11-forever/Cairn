# Cairn v0.1.1 — 一期 Windows 测试版

本版面向 Windows x64，供一期功能试用和安装反馈。[下载测试版及校验文件](https://github.com/orange11-forever/Cairn/releases/tag/v0.1.1-test)。

## 本版内容

- 项目、任务、知识资料、引用问答、多模型配置和个人项目智能体。
- 独立智能体管理页及项目管理对话：固定源智能体的模型和行为配置，另选工作项目，确认创建项目后继续管理新项目任务。
- 对话操作逐次预览确认；已确认记录按账号、智能体和工作项目保存，提交结果不明时先查询，避免重复执行。
- GitHub 登录与仓库授权、Monaco 编辑器、交互终端、独立工作区中的多 Agent 编程、命令审批、差异审阅、提交、推送和 PR。
- 山野路标界面、明暗主题、开场与任务完成动效、可调节的代码和知识工作区。
- 当前用户安装、同目录手动更新及保留用户数据的卸载；卸载清理已登记的当前/旧版程序文件和对应缓存，保留未知文件及用户数据。

## 安装与更新

测试文件名为 `Cairn-0.1.1-Windows-x64-test.exe`，配套 `SHA256SUMS.txt` 用于核对完整性。安装包不包含验收账号、用户数据或模型密钥。

在安装包所在目录打开 PowerShell，执行下列命令。将输出的 SHA-256 与 `SHA256SUMS.txt` 中安装包对应的值核对，一致后再运行安装程序。

```powershell
(Get-FileHash .\Cairn-0.1.1-Windows-x64-test.exe -Algorithm SHA256).Hash
```

完整程序路径须只含 ASCII 字符，可以包含空格；数据目录可使用中文。安装器检查 .NET Framework 4.8、WebView2 Runtime 和 VC++ x64 运行库，缺失时提供联网准备流程。当前测试机已具备这些组件，干净 Windows 的补装流程留待后续试装反馈。

更新前正常关闭应用，并从「账户 → 设置 → 数据管理」保存备份，再选择原程序目录安装。卸载保留应用数据；备份不包含模型或 GitHub 凭据，恢复后须重新配置或授权。安装后可在程序目录的 `README.md` 查看完整的备份与恢复步骤。

## 已知限制与二期范围

- 安装包尚未签名；当前采用手动安装更新，macOS/Linux 原生交付与自动更新仍待后续开发。
- 回答模型和 1024 维 Embedding 服务须分别配置；其他模型和复杂项目效果仍需单独验证。
- 独立管理对话只使用当前工作项目最近12条消息；未确认聊天仅保留在本页，已确认操作可重新查询。更长上下文、跨会话恢复及可查看、纠正和删除的长期记忆纳入二期。
- 飞书桌面身份/来源接入与剩余真实验收纳入二期，本版暂撤正常登录、绑定和知识页来源入口，保留既有实现与数据。
- 工作区布局尺寸尚不跨路由或重启保存。Agent 成果不自动合并；终端及编程命令以当前系统用户权限运行。

源代码采用 ISC 许可证，安装包保留 Cairn 及随包组件的许可证文件。
