## 修复与独立审查

补测复现并修复了四类畸形快照问题：非字符串正文、非字符串标题、超大 revision、非法标题 UTF-8。它们现在在对象写入前终止，不再进入通用自动重试路径。

按 `docs/review.md` 完成规格审查，再进行不同上下文的质量审查。质量审查发现并真实复现一项 P2：重复同步持资源锁、结果外键等待版本 KEY SHARE；索引发布持版本 FOR UPDATE、等待资源锁，形成死锁并消耗重试次数。

修复仅调整最终索引发布的版本锁为 FOR NO KEY UPDATE；保留写入互斥、job/attempt隔离、当前行刷新、资源/来源锁和旧版本保护。确定性的真实处理器并发测试先失败、后通过，要求两个任务都在第一次尝试完成。新增索引期间删除的回归保护。随后再次按规格复核→质量复核的顺序审查：P2已关闭，无剩余发现。
