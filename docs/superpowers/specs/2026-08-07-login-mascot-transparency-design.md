# 登录页看板娘透明化设计

日期: 2026-08-07
状态: 已确认, 待实现

## 背景

登录页第一轮视觉升级把无透明通道的全身看板娘包装成相框, 以避免米白图片背景直接贴在蓝色品牌区上。实际浏览后, 用户认为相框和米白底仍然割裂, 因此推翻原设计中的“保留不透明素材”约束, 改为制作透明全身图。

## 目标

- 保留当前看板娘的角色身份与完整全身姿态。
- 移除图片内部的米白背景与脚下灰色投影。
- 让人物直接融入登录页蓝色品牌区, 不再使用相框语言。
- 保持登录表单、认证流程、移动端头像和其他品牌元素不变。

## 素材设计

以现有 `cairn-mascot.png` 为编辑目标, 输出同目录下的新素材 `cairn-mascot-transparent.png`。

成稿要求:

- 画布保持 `1024x1536`, 使用 RGBA 色彩类型。
- 保留人物的五官、发型、绿色发夹、服装、书包、书本、姿态与比例。
- 保留头顶深蓝圆环与绿色圆点, 包括它们和人物之间的透明空隙。
- 完全移除米白底、背景晕染和脚下灰色投影。
- 发丝、衣袖和鞋子的边缘需要有平滑 Alpha, 不得出现明显白边或背景残留。
- 不增加文字、水印、新道具、地面、接触阴影或其他背景元素。
- 不覆盖原始 `cairn-mascot.png`, 以便对照和回退。

透明化只改变背景与边缘蒙版, 不重新设计角色。若自动背景移除会明显改变人物五官、发丝或服装细节, 应停止采用该结果并重新生成或精修, 不以角色失真换取透明背景。

## 页面接入

桌面端 `MascotFigure` 改用 `cairn-mascot-transparent.png`。移除现有相框的米白背景、内边距、轮廓和旋转, 保持当前布局占位和响应式尺寸, 避免登录卡片发生位移。

人物只使用轻柔的 `filter: drop-shadow(...)` 增加与深色背景的分离度。投影必须跟随透明轮廓, 不生成矩形阴影。移动端继续使用现有透明头像 `cairn-mascot-avatar.png`, 不重新裁切。

原始不透明全身图继续保留在仓库中, 但不再由登录页引用。

## 失败与回退

- 新素材加载失败时, 复用 `MascotFigure` 当前的图片错误状态, 不显示破损图片图标。
- 若透明边缘在蓝色背景上出现白边, 优先修正素材 Alpha 与去色溢出, 不用额外 CSS 描边掩盖。
- 若新素材影响桌面端占位, 调整图片自身渲染尺寸或 `object-fit`, 不改变登录页整体网格结构。

## 验收标准

- 文件是 `1024x1536` RGBA PNG, 四角 Alpha 为 `0`。
- 背景和脚下灰影均不可见, 人物、头顶圆环与绿色圆点完整。
- 在浅色和深色主题的蓝色品牌区上均无矩形底、米白边或明显抠图锯齿。
- 桌面、平板和移动端布局无溢出、遮挡或跳动。
- 现有登录行为、无障碍语义和图片错误状态不回归。
- Web 单元测试、React 测试、TypeScript 检查和生产构建继续通过。

## 影响范围

- `apps/web/public/assets/brand/mascot/cairn-mascot-transparent.png`
- `apps/web/src/components/MascotFigure.tsx`
- `apps/web/styles/main.css`
- 与素材引用和登录页视觉契约相关的测试

## 明确不做

- 不重绘或更换看板娘角色。
- 不修改移动端头像素材。
- 不调整登录页主色、wordmark、主题线或表单样式。
- 不修改认证逻辑、校验、错误处理、API 或焦点管理。
