# Stage 3B：项目共享来源的内容授权与撤回

日期：2026-09-24。接续来源登记与组织凭证解析，是持久化飞书同步的前置切片。

## 决策与范围

采用 `project_members` 显式共享策略：管理员登记共享，内容读取仍须当前项目 read 权限，资源变更仍须现有 write 权限。来源配置仅管理员可见。本授权切片使用迁移 0006 的来源表，不提供飞书逐用户授权；后续手动同步以迁移 0007 扩展请求持久化。

本切片将已登记来源状态接到全部已有内容读取、变更及索引发布边界。尚不创建飞书同步任务、不访问真实租户、不新增管理 UI。对象留存与即时访问撤回分开：停用不物理删除对象、历史版本或索引，但提交后所有新授权读取均不可见。已经签发的短时效对象 URL 遵循现有到期语义，不能声称可即时撤销已签发 URL。

## 授权不变量

- upload/zip_entry 保持现有项目授权语义；tencent_docs 等尚无授权实现的外部来源拒绝访问。
- feishu 必须对应同组织、同项目、provider=feishu、status=configured、access_policy=project_members 的来源；`source_id` 精确匹配规范 UUID 字符串，`external_id` 匹配登记文档。
- 资源与被读取版本的来源类型、来源 ID、外部 ID 必须一致；不可通过把其中一层改成 upload 绕过外部来源校验。缺失来源、错误引用、跨项目、跨组织、停用均失败关闭。
- 过滤须在 SQL 分页/检索候选截断之前完成，应用于资源列表、详情、下载、切片、关键词/向量搜索、引用加载、回答完成前再验证、重试及删除。不可见单体统一沿用 404；生成中撤回沿用 409 knowledge_changed。
- 批次详情若包含已绑定资源/版本且来源授权不满足的 item，则整批返回 404，避免暴露 item 元数据、资源 ID 或汇总计数；未绑定资源的待上传条目保持原有行为。当前批次创建仍为上传路径，这项防御不意味着支持来源同步批次。
- 读取所用版本（最新观察版本或当前发布版本）必须实际通过对应版本条件。资源软删除幂等语义和上传/压缩包路径保持原有行为。

## Worker 与并发

索引开始前及最终发布前都重新验证可信资源/版本/来源。最终检查读取最新数据库事实，不能使用 ORM 缓存的来源状态。发布与来源停用通过来源行锁串行化：停用先提交则发布拒绝；发布先锁住则停用等待，随后内容立刻被读取过滤。避免项目锁与资源/任务锁反向获取造成死锁。被撤回任务以固定安全错误终止，不泄露凭证/文档内容；复用已有安全错误契约，不扩展 API 错误枚举。初次拒绝时不得读取对象或调用 embedding，发布拒绝时索引与审计事务回滚。

## 验收

真实 PostgreSQL 覆盖可读成功、缺失/停用/跨租户/跨项目来源、混合来源类型和引用、分页、搜索双通道、回答中撤回、重试/删除及上传回归。Worker 覆盖开始前阻断、处理中停用、最终发布的并发锁与回滚、成功索引。已有数据库失败、未预期异常、CSRF、会话、安全头和 trace ID 契约不能退化；有修改的 HTTP 路径补充必要的消费者边界断言。公开路由/响应 schema 不变，检查 SDK 漂移。
