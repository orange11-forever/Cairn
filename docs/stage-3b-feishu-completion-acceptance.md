## 管理与部署

组织 owner/admin 可从项目知识页进入“飞书来源”，登记单个新版文档，明确确认项目成员共享，设置手动或 5 分钟至一周的同步周期，查看运行记录，手动同步，修改名称或凭证别名，停用和恢复。项目的管理授权仍由 API 验证。凭证别名由部署者在 Worker 的 `CAIRN_FEISHU_CREDENTIALS_JSON` 中按组织 UUID 配置；浏览器和来源 API 不接收 app secret、token 或文档正文。

需要在飞书开放平台为自建应用开通新版文档读取能力（`docx:document:readonly`，以租户平台实际审核的权限项为准），并确保目标文档允许该应用读取。登记只保存配置，不验证飞书权限；第一次手动或定时同步才会读取。`completed` 表示快照已保存，`resourceStatus=ready` 才表示可检索。停用会立即阻止新的内容读取；飞书侧撤权或删除须等下一次手动/周期检查观察到明确拒绝，最长传播时间还包含调度、租约及网络重试，不承诺即时发现。短时效已签发下载链接遵守原有到期时间。软删除的项目资料不会因同步自动复活，应由项目管理员处理。

真实租户只读前置检查使用仓库根目录被 Git 忽略、权限为 0600 的 `.env.feishu.local`，填入以下三个值：

```dotenv
FEISHU_TEST_APP_ID=
FEISHU_TEST_APP_SECRET=
FEISHU_TEST_DOCUMENT_URL=
```

`FEISHU_TEST_DOCUMENT_URL` 必须是 `https://feishu.cn/docx/<ID>` 或真实 `feishu.cn` 子域的同一路径。文档 ID 与显式命令参数必须完全一致。命令只读取该文档，不修改飞书。组织 UUID 和凭证别名用于明确本次检查对应的部署映射；CLI 本身直接使用临时本地凭证，不会读取或改写 `CAIRN_FEISHU_CREDENTIALS_JSON`：

```sh
python scripts/feishu-acceptance.py \
  --env-file .env.feishu.local \
  --org-id 11111111-1111-4111-8111-111111111111 \
  --credential-ref engineering_feishu \
  --document-id Doc123
```

运行时使用真实组织、别名和文档 ID，且部署 Worker 的 `CAIRN_FEISHU_CREDENTIALS_JSON` 必须将同一组织与别名指向同一应用凭证，才能把 CLI 结果与应用内同步比较。CLI 仅输出读取状态、安全失败码、耗时、revision 和正文 SHA-256；不输出正文、标题、凭证或 token。成功读取后仍需在已部署的管理页触发同步、等待 `resourceStatus=ready`，并用项目成员账号验证检索、停用与恢复。真实租户的周期和飞书侧撤权/删除传播只有实际执行并记录结果后才能标为通过。当前没有真实租户通过证据。
