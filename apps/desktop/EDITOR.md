# 本地代码编辑

在桌面版项目中进入「代码与架构 → 代码编辑」。关联 Git 仓库后，可以浏览目录、搜索文件路径、打开多个标签、新建 UTF-8 文件、编辑和保存。编辑器与差异视图使用随应用打包的 Monaco，不依赖 CDN。

随包许可证：[Monaco Editor](../web/public/licenses/monaco-editor.txt)、[DOMPurify](../web/public/licenses/dompurify.txt)、[Marked](../web/public/licenses/marked.txt)。

- 标签上的圆点表示未保存；点击「保存」或使用 Ctrl/Cmd+S 写入本地文件。新建文件需使用已有父目录。
- 「变更」列出 Git 已暂存、未暂存和新增文件。「差异」对照 HEAD 与磁盘内容；已打开文件使用当前草稿作为右侧内容。没有提交的新仓库以空内容为基线。此操作不会暂存、提交或推送代码。
- 保存发生外部版本冲突时保留草稿和磁盘内容。使用「对照磁盘版本」核对；「采用磁盘基线，保留草稿」只更新比较基线，仍须手动保存。
- 本次登录会话内，切换项目、任务/知识/代码视图后保留编辑标签及未保存内容。关闭未保存标签会询问是否丢弃；刷新页面时触发浏览器的未保存提示。退出登录或应用前应先保存，草稿不写入浏览器持久存储或普通备份。
- 更换仓库、分支或 HEAD 后，旧草稿保留但禁止直接保存。从文件树重新打开当前文件核对，再复制需要保留的内容。
- 操作记录显示本会话实际保存和失败结果。「已手动保存」仅标记本标签完成的人工保存；Git 变更列表不推断其他工具或 Agent 的修改来源。编程 Agent 面板另行展示本次文件修改、经确认执行的命令、实际输出与停止状态，详见[编程执行](CODING.md)。

## 文件边界

只读写当前用户、当前项目明确关联的工作目录。列表采用 Git 跟踪文件与未被忽略的新文件。支持最多 512 KiB 的 UTF-8 文本，保留 BOM、已有换行及 POSIX 可执行权限；二进制、其他编码、Git 内部文件、符号链接、目录联接、硬链接和特殊文件明确拒绝。

保存使用临时文件与原子替换，固定父目录句柄，并在写入前比较磁盘版本。冲突检测是乐观检查，不是与外部编辑器共用的文件事务锁：外部程序若恰在最后检查与替换之间写入，仍存在覆盖窗口。不把同用户工作目录保护描述成操作系统沙箱。

编辑器读取完整原始文件，和架构解析的截断、脱敏片段分开。仅打开、编辑、保存文件不会调用云模型；点击「解析项目架构」才发送明确展示的采样片段。保存后刷新采样，旧快照的架构报告不再作为当前结果显示。
